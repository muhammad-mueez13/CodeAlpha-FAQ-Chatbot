# AI FAQ Chatbot

An intelligent FAQ Chatbot developed as part of the **CodeAlpha AI Internship Program**. This project provides an interactive chatbot interface that retrieves the most relevant answers from a predefined knowledge base using NLP-inspired text preprocessing and similarity matching techniques.

## Features

* Interactive Chat Interface
* FAQ-Based Question Answering
* Similarity Matching Algorithm
* Confidence Score Display
* Chat History Storage
* Export Chat Functionality
* Responsive User Interface
* Dark Professional Dashboard Design
* Local Storage Support

## How It Works

1. User enters a question.
2. The text is cleaned and preprocessed.
3. Similarity matching is performed against stored FAQs.
4. The most relevant answer is selected.
5. A confidence score is generated.
6. The chatbot displays the answer to the user.
